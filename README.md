# Yukti Software - Central Administration Control Center

Complete, high-performance Admin Management Portal for Yukti Software.

## 🌟 Key Features

1. **Enquiries & Leads Management (`enquiries` collection)**:
   - Live view of all contact, course enquiry, demo booking, software development, and internship job applications.
   - 1-Click WhatsApp direct chat with pre-filled message.
   - 1-Click Email response.
   - Status updates (New, Contacted, In Progress, Enrolled, Closed).
   - CSV export for corporate record-keeping.

2. **Photo & Video Gallery (`gallery_photos`, `gallery_videos`)**:
   - Add, edit, and delete photos & student success videos.
   - Direct Cloudinary image upload or URL pasting.

3. **Meet the Team (`team_members`)**:
   - Manage executive leadership, mentors, and architects.
   - Photo upload, bio, skills/tech stack, and ordering.

4. **Internships & Careers (`internship_roles`, `internship_domains`)**:
   - Post live internship tracks with custom focus points and technologies.
   - Manage available domain seats.

5. **Courses Management (`courses`)**:
   - Add new dynamic courses to appear instantly on the website.

6. **Cloudinary Integration**:
   - Direct client-side unsigned media uploads without requiring a custom server.

7. **Settings & Security**:
   - GUI configuration for Firebase & Cloudinary keys.
   - PIN / Security passcode protection (Default: `yukti2026`).

## 🚀 How to Run

1. Open terminal inside `c:\Users\hinds\Desktop\yukti-admin`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the admin portal:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5174](http://localhost:5174) in your browser.
5. Enter Default Security Passcode: **`yukti2026`**
